# Design docs & mockups

- `design/state-model.md` is the **approved architecture** — code follows it; if reality diverges,
  update the doc in the same change.
- Mockups are self-contained HTML files in `design/`, built on the tokens in
  `frontend/src/styles.css` (there is no separate tokens file). Screenshot-verify a mockup
  renders correctly BEFORE presenting it for approval.
- Documentation is English only.
