Edit-target picker

The browser dock's Edit existing list, and the switch target menu of an open draft, become ONE picker. Each row says what the record is (type) and whose (authors) — two works sharing a name are told apart at a glance. A type row and + Filter narrow the list by any metadata field (built-in or yours), and every row can be opened in the library to check it before you capture into it. Everything below is live: type, click the chips, open + Filter, hover a row.

1 · No draft — ranked by this page
2 · Narrowed — type + a field filter
3 · Draft open — switch target
  • Row. Line 1: title + the existing badge (THIS PAGE / SAME NAME / n% MATCH). Line 2: the type tag and the authors (“no author” in muted italics when empty). Line 3: year · source site · how many entries. When the hit came from an alternative name, that name shows as an aka line instead of line 3, with the hit marked.
  • Search still covers title, alternative names and authors, ranked as today; the typed text is highlighted where it matched.
  • Type row: the library's types with their counts under the current filters — the typed text narrows the list only, since it ranks by similarity and counts taken another way would contradict it (a type with nothing left dims but keeps its place, so the row never jumps). One click narrows to that type, a second click clears it.
  • + Filter: the filterable fields (the same list the library's filter block offers, custom fields included), then the values of the chosen one with counts. Its search box finds fields and values (“horror” → Tags · horror). A picked value becomes a chip; × drops it. Same semantics as the library: values of a single-valued field are either/or, values of a list field narrow together.
  • Open in the library (the library icon, on hover): opens the title page in a library tab; middle-click opens it in the background, as everywhere else. Clicking the row itself still makes it the draft's target.
  • The switch-target menu (3) is the same picker, taller than today's 220px so the filters have room. Its badges now show the n% of a near match too (today they are blank there).
  • “New manga” becomes New title everywhere in the dock (button, eyebrow, the fresh-draft row) — already done in the working tree, shown here for context.
