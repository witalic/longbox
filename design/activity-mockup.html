Activity — what the app is doing, in one place

The corner of the sidebar already tells you about downloads; an import of a hundred gigabytes — or any other long job over the library (converting archives, a metadata run, a check) — had nowhere to show itself outside its own page. Both become activity: one button in the corner, one panel behind it. The button is there only while something is running or left unfinished.

  • One button. A running library job draws a ring of how far it is around the job's own icon (import, convert, metadata, check) and its percent; downloads keep their arrow and count. With both, the ring leads and the count follows.
  • It is hidden when there is nothing to show, as the downloads button is today.

  • LIBRARY is the one job over the library that can run at a time — an import, or a conversion, a metadata run, a check started in Settings. Its row says what it is, how far (files and bytes for an import, so a run of large videos still moves), the file it is on right now, and offers Stop (the file in flight finishes — the vault never holds half an entry) and the way back to the page that started it.
  • With no job running, the section says Nothing is running and the import's report stays where it is today, under Last runs in Import.
  • DOWNLOADS is today's list, unchanged — and the close-the-window warning lives in this panel as it does now.
