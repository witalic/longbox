Design mockup v3 · Phase 0

longbox — consolidated header, view modes, series edit

One header band for Library (collection selector by the title · Filters popover with a count · sort · a three-way Grid / List / Detailed view toggle) — identical in every view mode, no stacked strips. A clear ＋ Add flow. The Series page carries a View / Edit switch: View shows chapters & page tiles, Edit shows editable metadata with the Picker embedded below to parse straight onto the page.
