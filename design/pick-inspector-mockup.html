Clicking an element no longer auto-guesses a fragile selector. It opens an inspector: walk the ancestor breadcrumb, toggle exactly which tag / classes / id / attributes to match on, choose one vs all, and watch the live match count + highlight on the page. You anchor on stable things (a class, an href prefix) instead of a positional :nth — so it survives a refresh and works across titles.
