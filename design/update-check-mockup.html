Knowing a release is out

The app asks once whether it may check GitHub for new versions — two buttons of equal weight, neither chosen for the user. If yes, a release that is out shows as a quiet chip in the window's title bar; nothing is downloaded by itself. Settings → About changes the answer and checks on a click. Design note: design/update-check.md.

Check for new versions?

longbox can ask GitHub once a day whether a newer release is out, and tell you — with what changed, and whether it fixes the built-in browser's security. GitHub sees this computer's address and nothing else; nothing is downloaded by itself.

You can change this any time in Settings → About.
