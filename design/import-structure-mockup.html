The title above, written out. Typing a shape the ticks cannot draw turns the ticks off, and the title section says so. Tokens: {L0} {L1}… {folder} {creator}, a pattern's parts, and for entries {file} {n} {part} {date}.
Preview
  • WORK (radio): the level whose folders are works. Levels above only group them; folders below a work become its sections — the last row of the table says so.
  • TITLE (tick): this level's folder name goes into the work's title. Only the work and the levels above it can be ticked; a new profile ticks the work alone.
  • AUTHOR (tick): this level's folder name is the creator and fills the fields picked under the table. It replaces the Creator role: no tick, no author from folders.
  • The role switch, the per-level pattern fields, the Gives chips and the token paragraphs leave the main view. Advanced is closed by default and opens by itself for a profile that uses a pattern or a template the ticks cannot draw.
  • Nothing changes underneath: the ticks write the same workTitle template and the same level roles a profile keeps today, so saved profiles open as they are.
