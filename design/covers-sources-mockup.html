Covers & Sources

Two surfaces, four changes. Nothing new is invented here: the cover column already had a hover action bar, Sources already had groups and bookmarks in a saved order. What is added is a way to say which and in what order — and, for a site you are done with, a way to keep it without having it offered.

The strip is the stored covers only, in the order they rotate. Drag a tile to reorder — the first one is what every list, card and tooltip in the app shows. ✕ on a tile removes that one and closes the gap; the ✕ on the big cover still means "remove them all". ＋ picks an image file, exactly like the existing replace button.

FILE is the fourth change and the smallest: the name the archive or episode arrived under. The vault renames every stored file to the chapter's id, so without this the original name is gone. It is recorded per chapter at ingest and shown on the chapter's media column on hover; the row above is only here to say where it would read if it were a title-level fact — it is not, so it will NOT be drawn there.

Hover the first tile. A title with several covers fades through them while the pointer is on it and snaps back to the first when it leaves — a grid of hundreds animating on its own is not a grid anyone can scan, and the extra images are not even fetched until the first hover.

The third tile is a title nobody gave a cover. Rather than a coloured block it now shows what it actually holds: the first page of its first chapter, or — for an episode — the frame the player already cut for its tile. Several chapters means several stand-ins, so those rotate too. The badge is here only to make the mockup legible; the real tile draws no badge.

Group order is already stored as a list; it just has no way to be changed. Dragging a group header writes the new order, and both rails — the sidebar's GROUPS section here and the browser's source tree — follow it, because both are drawn from that same list. Bookmarks drag the same way, inside their source. Sorting the domains within a group stays the existing Titles / Name toggle in the header — the manual order is for groups, not for hundreds of domains.

Freeze is the other half of Remove. Remove hides a source and forgets its recipe; freeze keeps everything — the recipe, the bookmarks, the title count — and only stops the browser's rail from offering it. The row stays here, dimmed, with the button reading Thaw.
