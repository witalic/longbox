DECISIONS (v3)
  • Lead slot, not a dot column — one 14px slot holds the read dot (rows), the chevron (group headers) or the drag handle (edit mode). The label text starts at the same x in every row; reading state can't shift anything.
  • Nesting is a GROUP, not a glyph — translations render inside a container with a continuous guide line and a tinted background. Their read dots are smaller and sit on the line's rhythm; the lang/group badge is the row's name.
  • Fixed right columns — badge · pages (56px, right-aligned) · actions. Buttons land on one vertical in every row; empty page counts render blank, never a dash.
  • The label is ONE free-text field — "5", "5.5 Prequel", "2024 Artworks", "Extra"; smart sort parses the leading number. Field set everywhere: LABEL · LANGUAGE · GROUP · SOURCE LINK; the dock pre-fills SOURCE LINK from the active page (editable).
  • The dock shows no reading state — it manages capture/downloads; dots stay in the library. Entry edits never re-key the row (id stable → archive, read state, provenance bound).
  • Add images / Move pages — append into the entry archive (created on demand), renamed to continue numbering; moves rewrite both archives atomically. Move targets are CONCRETE entries: labels with several translations expand into them. Page reorder stays out of scope.
  • Re-grouping an entry — a group IS its label, nothing else is stored: drag a translation onto another label's row (or just edit LABEL in ✎) and it joins that group; the tree recomputes. Works in both directions — out of a group and into one.
  • Dock capture removed — the "read the chapter list off the page" capture (Add visible / Teach rows) is dropped entirely: untested across sites, unclear value. Entries are created manually or by downloads; “Add + arm download” merges creation with arming (details live in button tooltips, not panel copy).
