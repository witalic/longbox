Edit many titles

Pick titles in the library, open Edit fields, and see what they hold: every value with how many of them have it. Add a tag to all, take a character away from all, give a partial value to the rest, set a status — each click is a pending change, and one Apply writes them. Concept: design/bulk-edit.md.

4 · AFTER APPLY

One run, journaled — and undoable from the toast

Applied 4 changes to 37 titlesUndo

It is one Metadata operation over exactly the selected titles: one read and one write per title, the library's "updated" order kept, and the run in Metadata › History, where it can be reverted later too. A value changed since is never rolled back. Delete stays in the select bar — removing titles is not editing them.
