FFmpeg
======

longbox makes playable copies of episodes the window cannot show with ffmpeg, which ships
inside the app at

    resources/sidecar/_internal/imageio_ffmpeg/binaries/

It is a separate program the app runs; nothing of it is linked into longbox.

That executable is FFmpeg (https://ffmpeg.org), built with GPL components (libx264 and others),
and it is distributed under the GNU General Public License, version 3 — the full text is
GPL-3.0.txt beside this file (the repository's LICENSE: longbox itself is GPL-3.0-or-later).
FFmpeg is copyright the FFmpeg developers.

It is the build the imageio-ffmpeg 0.6.0 package carries for each platform
(https://github.com/imageio/imageio-ffmpeg, binaries from
https://github.com/imageio/imageio-binaries/tree/master/ffmpeg):

    Windows x64     ffmpeg-win-x86_64-v7.1.exe    FFmpeg 7.1 (gyan.dev essentials build)
    macOS arm64     ffmpeg-macos-aarch64-v7.1      FFmpeg 7.1
    macOS x64       ffmpeg-macos-x86_64-v7.1       FFmpeg 7.1
    Linux x64       ffmpeg-linux-x86_64-v7.0.2     FFmpeg 7.0.2

Running it with `-version` prints its exact version and the configuration it was built with.
